# Security Policy / 安全策略

## Reporting a Vulnerability / 报告漏洞

Use GitHub's private vulnerability reporting: open the **Security** tab of this
repository and select **Report a vulnerability**.

请使用 GitHub 私有漏洞报告：打开本仓库的 **Security** 标签页，选择 **Report a vulnerability**。

For non-sensitive issues, open a regular GitHub issue.

非敏感问题可直接提 GitHub issue。

## Scope / 范围

This repository contains prompt and checklist documents, not executable code.
Reports most relevant here concern:

本仓库包含提示词与清单文档，不含可执行代码。相关的报告主要涉及：

- Prompt-injection risks in the review pipeline
  审稿流程中的提示词注入风险
- Wording that could lead an agent to fabricate citations or verification results
  可能导致 agent 编造引用或核验结果的表述
- Leaked credentials or personal paths in any file
  任何文件中的凭据或个人路径泄露

## Response / 响应

Reports are acknowledged within 7 days.
报告将在 7 天内确认收到。
