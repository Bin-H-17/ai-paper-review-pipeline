# P3 附：对抗性总览（Adversarial Overview）

在 `paper-audit` deep-review（`--focus full`）**之后**、进入 P4 之前（或与 P3 并行整理），**必须**产出：

`03-deep-review/ADVERSARIAL_OVERVIEW.md`

（若产出根在 `review-pipeline/`，则路径为 `review-pipeline/03-deep-review/ADVERSARIAL_OVERVIEW.md`。）

本文件把「能审的」收成六栏必答（2026-08-21 新增栏 6 修辞偏见攻击）；「不能代做的」标边界。
语气：**找反例、找漏洞、找不足**；**禁止**排版/措辞/标点类抬杠。

---

## 必答六栏（每栏结构固定）

对每一栏写满：

1. **最强攻击（1–3 条）**：若审稿人想拒稿，最有力的攻击是什么？  
2. **文中锚点**：页/节/公式/表（可核对原文）。  
3. **是否站得住**：`站得住` / `部分站得住` / `站不住` / `证据不足（缺实验或未重算）`。  
4. **若站不住：最小补救**（改表述 / 补实验 / 收窄主张 / 改模型假设……）。

### 栏 1 — 数学逻辑自洽

- 定义、引理、推导、判据与后文使用是否一致？量词与假设是否闭环？  
- 与 P4 `math-proof-check` 衔接：此处写**全文级**自洽；逐块证明洞留给 P4。  
- 主动尝试：**何种反例/边界会使关键命题失效？**

### 栏 2 — 实验是否合理

- 设置是否匹配主张？缺对照/消融/灵敏度/基线时是否硬伤？  
- **不代做实验**；只评判设计与「应做未做」。  
- 输出「实验缺口清单」条目（可进 MASTER）。

### 栏 3 — 数据结果与结论是否合理

- 表/图/摘要数字是否互相矛盾？结论是否 overclaim？  
- **Claim–Evidence 硬规则**：凡「最优 / 证明 / 显著 / 首次 / 全程 / 实时」等强主张，必须钉到具体表、式、算法或代码输出。  
- 文中若写 smoke test、未大规模重算、临时数 → 必须标 **`Claim Risk`**，不得当终局证据。

### 栏 4 — 整个叙事是否成立

- 问题→方法→结果→结论是否一条链？有无逻辑跳跃、前后打架、摘要空洞？  
- 段落间因果是否倒置？证据是否撑住该段主题句？

### 栏 5 — 是否解决真问题、整篇是否有意义

- 题设/领域痛点是否被真正打中，还是自造 gap / 稻草人？  
- 相对 prior（接 P2）：增量是否可辨？若去掉本文方法，损失是什么？  
- 本栏是**审稿判断**不是实验室真理；结论写成「按现有文献与论证，贡献是否可辨认」。

### 栏 6 — 修辞偏见攻击（2026-08-21 新增）

> 依据：arxiv 2608.08975，120 篇 ICLR 实测，AI 审稿对证据呈现/创新性表述/研究范围高度敏感。

- 证据呈现是否过度包装？剥掉修辞后裸数值是否仍支撑结论？  
- 创新性表述是否靠修辞而非实质差异？对照 P2 查新结论。  
- 研究范围是否有不必要的收窄声明（收窄比扩大更危险）？  
- **整体偏见风险**：高/中/低。  
- 与 P3b `rhetoric-debias` 详细审查衔接：此处写攻击面摘要，逐条分析见 P3b 产出。

## 禁止与边界

| 禁止 | 边界（写进概述即可） |
|------|----------------------|
| 只挑字词、格式、标点 | 不代做实验、不编造数据 |
| 无锚点的空泛「写得不好」 | 无 S2/无代码时查新与复现降级，标 `[UNVERIFIED]` / 跳过 P5 |
| 与 deep-review 重复堆砌同质琐事 | 合并为「根因 + 最强攻击」 |

## 与其它阶段关系

- **P2**：栏 5 引用查新结论；未 verify 的 prior 不得支撑「首次」。  
- **P3 deep-review**：本概述是**浓缩攻击面**；详细 issue 仍在 deep-review 报告。  
- **P3b rhetoric-debias**：栏 6 修辞偏见攻击的详细展开。  
- **P4**：栏 1 指出的证明块 → 丢给 math-proof-check。  
- **P8 MASTER**：六栏结论摘要必须进入 `MASTER_REPORT.md` 对应章节。
