# 数学建模竞赛论文附加清单（校赛 / 国赛 / 美赛 / 亚太杯等）

在 P3 对抗性总览之后勾选。不适用（纯期刊 ML 稿）则在 MASTER 注明「非建模赛稿，本清单跳过」。

## A. 题意与真问题

- [ ] 重述是否覆盖题目**全部**必答问（含多问递进）？
- [ ] 核心机制是否按题意建模（例：光学遮蔽 ≠ 空间包裹）？是否指鹿为马？
- [ ] 「解决了什么」能否一句话说清，且与摘要/结论一致？

## B. 假设与模型

- [ ] 关键假设是否过强或不可检验？放松后结论是否可能垮？
- [ ] 符号表与正文公式一致？有无未定义就使用的量？
- [ ] 公共子模型是否在后续问中被错误改写或静默替换？

## C. 递进结构（Q1→Qn）

- [ ] 复杂度递进是否真实（变量维数、约束、目标），而非换皮重复？
- [ ] 后问是否合理复用前问子模型？复用时条件是否写明？
- [ ] 各问最优/可行结论是否互相矛盾（无解释）？

## D. 求解与可复现

- [ ] 算法流程是否可按文复现（输入、约束、目标、停止准则）？
- [ ] 启发式 / 元启发式是否说明随机种子、次数、失败如何处理？
- [ ] 有代码时：主张是否与脚本输出一致？（交 P5，此处只勾「需核验」）

## E. 结果、灵敏度与结论

- [ ] 表图数字与摘要一致？量级是否物理合理？
- [ ] 是否有灵敏度 / 鲁棒性 / 极限工况？字典序贴边界是否被讨论？
- [ ] smoke / 未重算是否被当成终局结论？（必须 Claim Risk）
- [ ] 推广与评价是否空泛套话、与前文结果脱节？
