# 何时动 SymPy

SymPy = Python 符号计算库（展开、化简、求导积分、验证代数恒等式）。  
**管演算，不管证明逻辑。**

## 该用

- 多项式/有理式展开与化简是否相等
- 矩阵乘法、迹、范数代数恒等
- 求导/积分/求和的形式核对
- 拟合式、误差界里的纯代数步骤

## 不该用（标「对书/人工/Lean」）

- 存在性、唯一性论证
- 群作用、等变性、范畴论式推理
- 需要选择公理/测度论细条件的步骤
- 「由引理 X 得」这类引用是否合法

## Round 1 执行约定

默认 `--sympy auto`：

1. 从「可疑/错」行里筛代数候选
2. 写最小脚本（优先 `python -c` 或工作目录临时 `.py`）
3. 把通过/失败写进该块 `review.md` 的 SymPy 节
4. 跑完可删临时脚本；保留命令与结论在报告里

无 SymPy：`pip install sympy` 失败则跳过并在 REPORT 注明「未跑符号复核」。
