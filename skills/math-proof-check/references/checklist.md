# 洞检 Checklist（Round 1）

## 必查项

- [ ] 定义是否在使用前给出，且全文一致
- [ ] 每个「因此/故/于是」是否有充分前提
- [ ] 量词顺序（∀∃）有无偷偷调换
- [ ] 有限群 / 紧群 / 离散群 条件有无扩大使用
- [ ] 群作用：自由、忠实、传递等是否被默认
- [ ] 表示：酉性、有限维、不可约是否被默认
- [ ] 等变性：左/右作用、规范化常数是否一致
- [ ] 轨道-稳定子：公式适用的假设是否齐全
- [ ] 测度/积分换序是否有控制定理或有限性借口
- [ ] 不等式方向、常数依赖性是否说清
- [ ] 引用前文引理时，引理假设是否被当前设定满足
- [ ] 「同理」步骤两边结构是否真同构
- [ ] 边界情形（单位元、平凡表示、单点轨道）是否炸

## 判定口径

| 判定 | 含义 |
|---|---|
| OK | 本步在已列假设下可直接核对 |
| 可疑 | 可能有洞、跳步或隐含假设；需复核 |
| 错 | 在已给设定下不成立，或明显条件偷换 |

## 严重度（写入 REPORT）

- **Critical**：核心定理依赖的步骤错/条件偷换
- **Major**：引理级漏洞或关键跳步
- **Minor**：表述缺口、可补的隐含假设、局部「显然」
